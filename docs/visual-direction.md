# Visual direction

A cinematic archive-room visual language: dark walnut, aged paper, muted brass, warm ivory, and restrained oxblood accents. Editorial serif headlines sit beside clean sans-serif body copy and monospaced archive metadata. The visual language is inspired by physical case folders, pinboards, desk lamps and research rooms rather than generic dashboard cards.

The live hero uses original bundled vector artwork (`frontend/public/images/investigation-wall.svg`). Case cards use layered CSS artwork and the evidence board uses parchment-style interactive React Flow nodes. The forensic module has a separate vector plate. The earlier generated moodboard is retained in `docs/` as a visual reference only.
